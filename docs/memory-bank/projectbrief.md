# Project Brief: Doon International School Website

## Core Goals
Build a modern, accessible, and performant website for Doon International School that serves as their primary digital presence and communication channel for prospective students, parents, and the community.

## Key Deliverables
- **Static-First Website**: Content-driven site using JSON data sources
- **Responsive Design**: Mobile-first approach optimized for all devices
- **Performance Focus**: Fast loading with Next.js optimizations
- **Accessibility**: WCAG 2.1 AA compliant
- **Inquiry System**: Functional contact forms with email notifications

## Scope
- School information pages (About, Admissions, Discover, Gallery)
- News and updates section
- Contact and enquiry functionality
- Responsive design with animations
- Performance optimized for visitors

## Technology Constraints
- Next.js 14 with App Router (framework lock-in)
- TypeScript for type safety
- Strict constitutional governance (SDD methodology)
- Static-first content management

## Success Criteria
- Clean, professional design reflecting institutional values
- Fast loading (<3 seconds first contentful paint)
- Working email enquiries and contact forms
- Fully accessible interface
- Easy content updates through JSON files
